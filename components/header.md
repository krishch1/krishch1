# KRON.OS Header Component

---

# Purpose

The Header is the first impression of KRON.OS.

It should immediately communicate that this is not a traditional GitHub README.

It should feel like the startup interface of a premium Artificial Intelligence Operating System.

The Header occupies the first viewport of the GitHub profile.

It must establish the complete visual identity of KRON.OS.

---

# Responsibilities

The Header is responsible for displaying

- Hero SVG
- Brand Identity
- System Boot
- User Identity
- Quick Navigation
- System Status

Nothing else.

GitHub statistics do NOT belong here.

Projects do NOT belong here.

Technology stack does NOT belong here.

# Technical Rules

Use HTML inside Markdown when layout precision is required.

Hero SVG must remain external.

Never embed raster images.

No JavaScript.

No external frameworks.

Everything must work inside GitHub Markdown.

# Goal

When someone opens the GitHub profile they should immediately think

"This isn't a GitHub README."

"This feels like the startup screen of a premium AI operating system."

The Header defines the entire KRON.OS experience.

Every section below it should visually inherit this design language.
